# Learnova 📚

**Study Smarter, Not Harder.**

Learnova is an AI-powered study assistant that helps students prepare for exams by analyzing a syllabus and up to five previous question papers. It aims to identify important and recurring topics, generate study notes and practice questions, and support smarter exam preparation.

### ✨ Key Features
- Upload a syllabus PDF and up to five previous question papers.
- Extract and analyze academic content using AI.
- Identify important and recurring topics.
- Generate study notes and practice questions.
- Support more efficient exam preparation.

### 🛠️ Tech Stack
React · Vite · Tailwind CSS · Node.js · Express.js · Ollama · Gemma 2B

### 🚀 Getting Started
1. Clone this repository.
2. Run `npm install` in both `client` and `server`.
3. Install Ollama and run `ollama pull gemma2:2b`.
4. Start the backend with `node server.js`.
5. Start the frontend with `npm run dev` inside `client`.

**Note:** AI analysis requires the backend and Ollama to be running. Some features are planned and may not yet be implemented.
